## What your sponsorship pays for

- **Code signing.** Signed macOS and Windows builds so the desktop app installs without
  security warnings. Signing certificates cost money every year.
- **Security work.** Reviews, dependency updates and quick fixes for reported issues.
- **New features.** The agent, mobile build integrations and more of the
  [roadmap](https://github.com/benzid-wael/secure-vault).
- **Docs and support.** Keeping this guide accurate and answering issues.
